# FrameEnd

Плагин для Paper/Purpur серверов (1.21+), реализующий динамический циклический ивент открытия Эндермира, поэтапные испытания, битву с боссом Эндер-Драконом, охоту за Яйцом Дракона и уникальную экономическую механику установленного яйца с износом и Компасом Дракона.

## Основные возможности

- **Расписание открытия Эндермира**: Автоматическое открытие 2 раза в неделю в 18:00 по МСК с настраиваемыми оповещениями в чат.
- **Изоляция центрального острова**: Портал на спавне активен только во время ивента; игроки не могут покинуть центральный остров дракона.
- **Фаза 1: Якоря возрождения**: Спавн якорей с ценными ресурсами и шанс появления Секретного Обелиска с редчайшим лутом.
- **Фаза 2: Древний Эндер-Дракон**: Кастомный босс с динамическим босс-баром, системой подсчета урона и наградой в виде фреймов (донат-валюты) для топа игроков.
- **Фаза 3: Охота за Яйцом Дракона**: Яйцо с 500 единицами прочности, подсветка захватившего игрока и эвакуация через портал.
- **Механика установленного Яйца Дракона**: Пассивный доход в секунду, глобальное оповещение с частично скрытыми координатами, износ при генерации монет и система починки (за валюту, опыт или донат).
- **Компас Дракона**: Артефакт для вычисления точных координат установленного яйца с перезарядкой раз в 2 дня.
- **Интеграции**: Поддержка Vault, PlayerPoints и PlaceholderAPI.

## Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/fe start` | Принудительно запустить ивент | `frameend.admin` |
| `/fe stop` | Принудительно остановить ивент | `frameend.admin` |
| `/fe next` | Переключить следующую фазу ивента | `frameend.admin` |
| `/fe giveegg <игрок>` | Выдать Яйцо Дракона | `frameend.admin` |
| `/fe givecompass <игрок>` | Выдать Компас Дракона | `frameend.admin` |
| `/fe reload` | Перезагрузить конфигурацию | `frameend.admin` |
| `/dragoncompass` | Использовать Компас Дракона | `frameend.compass.use` |

## Плейсхолдеры PlaceholderAPI

- `%frameend_status%` — статус ивента (Активен / Не активен)
- `%frameend_phase%` — текущая фаза ивента
- `%frameend_next_event%` — время до следующего открытия
- `%frameend_portal_open%` — открыт ли портал (true/false)
- `%frameend_placed_eggs_count%` — количество установленных яиц в мире
- `%frameend_compass_cooldown%` — оставшееся время перезарядки компаса
